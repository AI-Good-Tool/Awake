醒咖 是一款原生 macOS 菜单栏防休眠工具：屏幕常亮、后台任务和演示模式，可搭配 App 白名单、定时规则、低电量与温度保护。

### 0.2.5 更新

- 应用显示名称统一为「醒咖」，同步更新应用程序名称、设置窗口、关于页、菜单与安装器标题。
- 新增 7 款无蒸汽菜单栏图标：经典杯、圆角马克杯、矮胖拿铁杯、直壁意式杯、外带纸杯、小摩卡壶、原生咖啡杯。
- 在「总览 → 菜单栏图标」点选即可切换并保存选择；全部样式支持实心运行、空心关闭／暂停，以及系统单色模式。
- 默认运行颜色改为蓝色 `#00A8FF`，提供「恢复默认蓝色」按钮。之前默认灰绿色的配置升级为蓝色，其他自定义颜色继续保留。
- 保留已有图标选择、电源策略、白名单与定时规则。默认使用无蒸汽经典杯。

检查更新需要主动点击。下载后请先从菜单栏正常退出醒咖，再安装新版替换应用；当前不在后台自动替换运行中的程序。

### 下载与安装

- **DMG**：打开磁盘映像，把「醒咖」拖到 Applications。
- **PKG**：使用 macOS 安装器安装到 `/Applications`。
- **ZIP**：解压后将应用移到「应用程序」。
- **SHA256SUMS.txt**：以上文件的 SHA-256 校验值。

系统要求：**macOS 26 或更新版本**。应用与安全看门进程均为 **Universal 二进制（Apple Silicon / Intel）**。

### 首次使用与升级

本次分发采用 ad-hoc 应用签名；PKG 没有 Developer ID Installer 签名，也未进行 Apple 公证。macOS 可能显示无法验证开发者或无法检查恶意软件的提示。确认来自本仓库后，可在「系统设置 → 隐私与安全性」中允许打开。

升级前请从旧应用菜单正常退出。应用现名为「醒咖.app」；若仍有「醒咖 Awake.app」，安装后可将其移到废纸篓，避免出现两个图标。已使用醒咖的用户保留配置；从 Lidwake 升级时，首次启动会复制旧偏好、白名单与规则，开机启动需在醒咖内重新开启。

默认保持唤醒使用 macOS 电源 assertion，不能保证绕过系统闭盖限制。「强制闭盖后台运行」需要显式开启与管理员授权，会修改 `pmset disablesleep`；暂停、关闭或退出时会尝试恢复，独立看门进程处理异常退出，开机恢复规则提供额外保护。
